# Sổ kế toán TT133 — by iFix Laptop

Phần mềm sổ kế toán theo Thông tư 133 cho nhiều công ty, chạy trên máy tính Windows, mở bằng trình duyệt.
Dữ liệu nằm trên máy của bạn.

## Tải về

**[Tải file cài đặt mới nhất](cai-dat/SoKeToan-CaiDat.exe?raw=1)** (Windows 10/11)

1. Chạy file cài đặt, bấm Next → Install → Finish. Nếu Windows báo "Windows protected your PC", bấm **More info** → **Run anyway**.
2. Bấm biểu tượng **Sổ kế toán** trên Desktop.
3. Dùng thử đầy đủ chức năng 30 ngày, tối đa 3 công ty. Mua bản quyền: gửi **Mã máy** (trang Bản quyền trong phần mềm) qua Zalo.

Phần mềm tự báo khi có bản mới: **Cài đặt chung → Cập nhật → Cập nhật ngay**. Dữ liệu và key giữ nguyên.
